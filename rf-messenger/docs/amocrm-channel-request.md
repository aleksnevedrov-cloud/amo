# Заявка в техподдержку amoCRM: регистрация канала API чатов

Отправляет **владелец интеграции** (заказчик) из аккаунта aleksnevedrov.amocrm.ru: чат поддержки в amoCRM
или support@amocrm.ru. До отправки нужно создать в amoCRM **внешнюю интеграцию «РФ-Мессенджер»**
(«amoМаркет» → «Создать интеграцию» → «Внешняя»), загрузить в неё `widget.zip` и указать ссылку
для перенаправления `https://chat.rf-dveri.ru/`. Её ID интеграции подставляется в заявку.

**Тема:** Регистрация канала чатов (Chat API) для собственной интеграции

Здравствуйте!

Просим зарегистрировать канал чатов (API чатов, amojo) для нашей интеграции.

| Поле | Значение |
|---|---|
| Аккаунт | aleksnevedrov.amocrm.ru |
| Интеграция | «РФ-Мессенджер», ID интеграции: `<ID интеграции из amoCRM>` |

Просим прислать **ID канала** и **секретный ключ** канала. Также просим подтвердить, что для нашего канала
работают: статусы доставки, ответ с цитатой, отправка сообщений с телефона менеджера как исходящих
(sender — менеджер, receiver — клиент) и запуск Salesbot в чатах канала.

## Что сделать после ответа amo

1. Записать ID канала и секрет в `/opt/rf-messenger/.env`: `AMOJO_CHANNEL_ID`, `AMOJO_CHANNEL_SECRET`.
   В переписку, задачи и git секрет не копировать.
2. `docker compose up -d` в `/opt/rf-messenger`.
3. Открыть настройки виджета «РФ-Мессенджер» → «Подключить к amoCRM». Виджет берёт amojo_id аккаунта
   и подключает канал (`POST /v2/origin/custom/{channel_id}/connect` → `scope_id`).
4. Подключить тестового Telegram-бота и пройти приёмку этапа 1 (`docs/stage-1-report.md`).
