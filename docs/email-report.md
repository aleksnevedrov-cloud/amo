# Отчёт: подключение почты

По решению заказчика — отдельное подключение к почтовому ящику (IMAP + SMTP), вне Salesbot.

## Что сделано

| Что | Где |
|---|---|
| Опрос ящика раз в минуту, только чтение, без обработки старых писем | `packages/mail/src/poller.ts`, воркер `poll-mail` |
| Привязка письма к открытой сделке контакта, создание контакта и сделки | `packages/mail/src/link.ts`, `packages/amo` (поиск контактов, `leads/complex`) |
| Разбор писем: текст/HTML, вырезание цитат и подписи, вложения | `packages/mail/src/parse.ts` |
| Фильтры: автоответы, рассылки, noreply, свои письма, исключения, лимит ответов на адрес | `parse.ts`, `poller.ts` |
| Ответ в цепочку (Re:, In-Reply-To, References), подпись, копия в «Отправленные», примечание в сделку | `packages/mail/src/reply.ts`, `channel.ts` |
| Режимы «Авто», «Полуавто» (письмо уходит сразу после одобрения), «Подсказки» | `packages/agent/src/pipeline.ts`, `apps/api/src/routes/widget-phase2.ts` |
| Пауза AI, когда менеджер ответил клиенту письмом | «Отправленные» → `email_manager_activity` |
| Пароль приложения — зашифрован, только запись; проверка подключения IMAP/SMTP | `apps/api/src/routes/widget-email.ts` |
| Вкладка «Почта» в настройках: сервисы Яндекс / Mail.ru / Gmail, статус, исключения | `apps/widget/src/components/EmailSettings.tsx` |

Тесты: 285 (было 245). Адаптеры IMAP и SMTP проверены на настоящих протоколах — локальный IMAP-сервер
(hoodiecrow) и SMTP-сервер (smtp-server): выборка новых писем, «Отправленные», копия ответа, отправка в цепочку,
отказ при неверном пароле. Собранный API проверил подключение к этим серверам через «Проверить подключение».

## Решения заказчика

- Почта уже подключена к amo; новые клиенты попадают в «Неразобранное» — AI сделок не создаёт.
- AI отвечает только клиентам в сделках. «Неразобранное» сделкой не считается: письмо нового клиента ждёт,
  пока менеджер примет заявку (по умолчанию до 60 минут), затем AI отвечает в сделке. Поставщикам, сервисам
  и сотрудникам без сделок AI не отвечает.
- Ответ AI виден в переписке сделки через «Отправленные»; примечание-дубль выключено.

## Что нужно от заказчика

Адрес ящика, почтовый сервис и **пароль для приложений** (вносится в настройках виджета, в переписку не нужен).

## Важно

- Проверка на живом ящике заказчика — после получения доступа: реальные серверы могут отличаться от тестовых
  (названия папок, ограничения на частоту подключений).
- Вложения писем — в фазе 3 вместе с фото и документами из чатов.
