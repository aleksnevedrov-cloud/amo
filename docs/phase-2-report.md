# Отчёт: фаза 2 — Продажи

## Критерии приёмки (раздел 15 ТЗ)

| Критерий | Статус |
|---|---|
| Eval-набор проходит | ⏳ Набор расширен до 30 диалогов (расчёт, нестандарт, задачи, память, скидка в расчёте). Живой прогон — после появления ключа Anthropic (отложено по решению заказчика). Ожидаемые итоги расчёта в диалогах сверяются с калькулятором тестом. |
| Расчёт совпадает с ручным на 10 примерах | ⏳ 3 из 3 полученных примеров совпадают до рубля при правилах, выведенных из накладных (89222 — 210 873 ₽; 89190 — 138 600 ₽; 87583 — 125 330 ₽ с учётом ручной скидки менеджера). 4-й пример (88959, двустворчатая) показал, что нужно отдельное правило. Остальные 7 примеров и реальные правила — при обучении. |

## Что сверить на живом аккаунте amo (п. 0.3 ТЗ)

1. **Запуск бота по API** `POST /api/v2/salesbot/run` — формат запроса.
2. **Второй обработчик виджета** в конструкторе Salesbot (`ai_send`) и передача кода обработчика в `onSalesbotDesignerSave`.
3. **Ссылка на голосовое** в Salesbot: как передать `attachment_url` в шаг виджета. Без неё голосовые приходят
   без вложения, и агент просит написать текстом.
4. **«Вставить в чат»**: поле ответа ищется по разметке amo; если не найдено — текст копируется в буфер обмена.
5. Пункты фаз 0–1 (события `outgoing_chat_message`, формат continue, хук отключения).

## Отклонения от ТЗ

- **Поля сделки** (`crm.update_fields`) не заполняются — по ответу заказчика данные идут в «Детализацию» вручную.
  Вместо этого — черновик детализации.
- **Резюме при закрытии сделки** не сделано автоматически: нужен вебхук смены этапа. Есть резюме при
  передаче и по кнопке. Добавлю вместе с вебхуками, если нужно.
- **Стоимость расшифровки голосовых** в журнале не учитывается (у провайдеров тарификация по секундам).
- Новые пакеты `packages/pricing` и `packages/media` (в разделе 17 их нет): расчёт нужен API (тест расчёта)
  и воркеру; расшифровка — отдельный модуль под фазу 3 (фото, документы).

## Что понадобится при обучении

1. Правила расчёта: состав комплекта, цены комплектующих по сериям, наценка за нестандарт, услуги
   (доставка по зонам и км, подъём/занос, монтаж), правило для двустворчатых дверей.
2. Ещё 7 примеров расчётов (до 10 для приёмки).
3. Виджет документов: разработчик и способ записи в «Детализацию».
4. Фид каталога, ключ Anthropic, ключ SpeechKit (или Whisper).
5. Бот-отправщик для «Полуавто» (если режим нужен).
