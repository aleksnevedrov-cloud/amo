# Подключение Яндекс Почты к AI-агенту

Ящик: **rf-dveri@yandex.ru** (личная Яндекс Почта).

Инструкция на момент запуска: бэкенд установлен, виджет — в amoCRM. Занимает ~5 минут.
Названия пунктов в интерфейсе Яндекса могут немного отличаться — ориентируйтесь по смыслу.

## 1. Разрешить почтовым программам доступ к ящику

1. Войдите в Яндекс Почту rf-dveri@yandex.ru.
2. Шестерёнка → «Все настройки» → «Почтовые программы».
3. Отметьте «С сервера imap.yandex.ru по протоколу IMAP».
4. Способ авторизации — «Пароли приложений и OAuth-токены». Сохраните.


## 2. Создать пароль для приложения

1. Откройте id.yandex.ru (Яндекс ID) под rf-dveri@yandex.ru → «Безопасность» → «Пароли приложений».
2. «Создать пароль» → тип «Почта» → название, например «AI-агент amoCRM».
3. Скопируйте пароль — Яндекс покажет его один раз.

Этот пароль работает только для почты и отзывается в том же разделе. Основной пароль ящика не нужен.

## 3. Ввести в настройках виджета

amoCRM → Настройки → виджет «AI-продавец дверей» → вкладка «Почта»:

1. Кнопка «Яндекс» — серверы заполнятся сами:
   входящие `imap.yandex.ru`, порт 993, SSL; исходящие `smtp.yandex.ru`, порт 465, SSL.
2. «Логин» — `rf-dveri@yandex.ru`.
3. «Пароль приложения» — вставьте пароль из шага 2 → «Сохранить пароль».
4. Остальное уже настроено под вас: отвечать только клиентам в сделках, ждать принятия заявки из
   «Неразобранного», примечание-дубль выключено. Проверьте подпись → «Сохранить».
5. «Проверить подключение»: должно быть «подключено» для входящих и отправки и найдена папка «Отправленные».
6. Отметьте «AI отвечает на письма клиентов» → «Сохранить».

## Если не подключается

| Сообщение | Что сделать |
|---|---|
| `AUTHENTICATIONFAILED`, `Invalid login`, `535` | Проверьте логин (полный адрес) и пароль приложения; включён ли IMAP и «пароли приложений» (шаг 1) |
| Папка «Отправленные» не найдена | Впишите `Отправленные` в поле папки вручную |
| Ошибка только у отправки (SMTP) | Проверьте, что пароль создан с типом «Почта» |

Пароль хранится в системе в зашифрованном виде и нигде не показывается. Чтобы отключить AI от почты —
снимите галочку «AI отвечает на письма клиентов» или удалите пароль приложения в Яндекс ID.
