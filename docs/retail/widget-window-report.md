## Как отправляется ответ (п. 3)

**Выбрано: Wazzup API от имени менеджера.** `POST https://api.wazzup24.com/v3/message` передаёт `channelId`, `chatId` и `chatType` последнего входящего сообщения клиента по этой сделке, а также `crmUserId` = id пользователя amo, нажавшего кнопку.

- Wazzup сам показывает сообщение в чате карточки amo — так же, как ответ менеджера из чата.
- Ключ Wazzup берётся из настроек (вкладка Wazzup), формат настроек не менялся.

Почему не другие пути:

- **Чат amo (amojo / API чатов).** Отправка от имени менеджера требует регистрации собственного канала чатов в amo и подписи `X-Signature` секретом канала. У интеграции такого канала нет — клиенты пишут через канал Wazzup. Сообщение из «нашего» канала ушло бы не в WhatsApp клиента, а в отдельный чат.
- **Salesbot `continue`.** Работает только внутри запущенного бота, отправка «по кнопке» в любой момент так невозможна. Бот-отправщик остаётся для черновиков «Полуавто», как раньше.

**Запасной вариант «Скопировать» / «Открыть чат».** Включается, когда отправить через Wazzup нельзя:

- Wazzup не подключён;
- клиент писал только на почту или в чат amo без Wazzup;
- у контакта нет телефона.

Причина пишется рядом с кнопками.

**Ограничения 5а.4:**

- отправка только по кнопке;
- только в чат клиента текущей сделки — канал и чат берутся сервером из его последнего входящего, адрес из виджета не принимается; группы исключены;
- повтор заблокирован дважды: в виджете кнопка недоступна до ответа, на сервере — параллельная отправка в ту же сделку (409 «busy») и тот же текст повторно в течение 20 с (409 «duplicate»);
- каждое отправленное сообщение — запись `manager_send` в журнале: кто (`userId`, имя), когда, канал, `channelId`, текст. Отказ Wazzup — запись «Ошибка» «Ответ менеджера не отправлен (WhatsApp): HTTP …».

**Поведение агента.** Ответ менеджера из окна — то же, что ответ менеджера в чате: AI встаёт на паузу «Менеджер написал клиенту». Об этом сказано под кнопкой. Сообщение пишется и в диалог агента ролью «менеджер» — после «Возврат AI» агент видит, что ответил менеджер.
