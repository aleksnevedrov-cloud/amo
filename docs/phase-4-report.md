## Решения по ответам заказчика

| Вопрос | Ответ | Решение |
|---|---|---|
| DWG | Конвертировать на сервере | LibreDWG `dwg2dxf` → DXF → текст надписей и размеров с координатами (точнее OCR). Без конвертера — понятная ошибка, AI просит PDF. |
| Биллинг | Пока только учёт расходов | Расход по месяцам (₽, $, токены, диалоги) во вкладке «Аналитика». Тарифов нет; при решении о платной публикации — фаза 5. |
| Конверсия | Любой переход вперёд по воронке | Стартовый этап запоминается при первом ответе AI; раз в 6 часов этапы перепроверяются, «вперёд» = этап дальше по порядку или успешное закрытие. |
| Веб-поиск | Не нужен | Не делался; в настройках раздела нет. |
