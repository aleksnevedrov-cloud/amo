# KP-SEND-LAYER: окно письма «Отправить клиенту» было под окном КП

Дата: 20.10.2026. Ветка `claude/opt-kb`, коммит `39a8796` (после `aef9c4f`), +77 / −20 строк. Виджет 2.0.2.

Миграций нет, сервер не менялся. Розница и ядро не менялись: `git diff 06d538d -- packages/retail apps/api apps/worker apps/widget packages/core` = 0.

## Что было (сделка 90025, черновик 62)

«Отправить клиенту» в окне КП → `GET /kp/send/preview` 200, `POST /kp/send` — ни разу.

Причина — первая из двух возможных. Окно письма (`SendPreview`) без своего слоя: в 2.0.0–2.0.1 оно рисовалось карточкой в узкой колонке amoCRM. Окно КП — фиксированный слой на весь экран (`z-index: 10000`). Оно закрывало карточку письма с кнопкой «Проверено, отправить», поэтому нажать её было нельзя.

Блокировки отправки (нет e-mail, нет файла КП) тут ни при чём: они показываются текстом «Нельзя отправить: …» в самом окне письма.

Тест виджета этого не ловил: он искал текст во всей странице, а не то, что видно сверху.
