# KB-WEB-ROWS: цены в КП — только из прайсов, интернет убран

Дата: 19.10.2026. Ветка `claude/opt-kb`, коммит `026c788` (после 6ada918). Сервер (`@opt/kb`, `@opt/kp`, `apps/opt-api`) и виджет 1.2.7.
Миграций нет, строки базы не удалялись. Розница и ядро не менялись (`git diff 06d538d -- packages/retail apps/api apps/worker apps/widget packages/core` = 0).

Файл задания «Задание-Коду-KB-WEB-ROWS.md» до Кода не дошёл. Сделано по описанию в сообщении и по ответу на вопрос
(«Убрать интернет совсем»): цена в КП — только из прайса или введённая менеджером руками в черновике.

## Что было (89813, черновик 69, 136 позиций)

26 позиций получили цену не из прайсов: 19 дверей (ДПГУЧ — 3 строки, «Аква 01 ПГ» — 10, ещё 6) и 7 строк фурнитуры.
Причин две:

| Причина | Где |
| --- | --- |
| Подбор брал строки базы любого происхождения: строки прайса нет — строка от закупки, правка менеджера, веб-строка. ДПГУЧ — веб-строка 35 (40 029,67 ₽, 1 источник), Аква — веб-строка 183 (14 453 ₽). В плитке такая цена была подписана «из базы знаний» | `lookupPrice` (`packages/opt/kb/src/prices.ts`) |
| Строки нет вовсе — веб-поиск, а его цена писалась в базу (доверие 40) и дальше шла в другие КП как «из базы»; правка менеджера писалась в базу (доверие 90) так же | `runResearchJob` (`packages/opt/kp/src/research-job.ts`), `PUT /kp/draft/:id` (`apps/opt-api/src/routes/kp.ts`) |

| Старые черновики | `routes/kp.ts` (`dropNonPriceListPrices`), `researchablePositions` | при «Найти цены» и при «Собрать документ» цена не из прайса снимается: прежний веб-поиск («по рынку», «по аналогу») и строка базы не из прайса (веб, правка менеджера, закупка). Позиция становится «цена не из прайса» — «уточнить у менеджера», без цены. В журнал: «Цены не из прайса сняты: N поз.». «Найти цены» по всем берёт такие позиции заново |
| Документ | `packages/opt/kp/src/kp-build.ts` | цена «по рынку» / «по аналогу» в таблицу и итог не идёт (строка — «уточнить у менеджера») — даже если черновик собирают в обход маршрута |
| Виджет 1.2.7: карточка сделки | `apps/opt-widget/src/components/KpBlock.tsx` | кнопок «Искать в интернете» и «Искать заново» нет, у позиции одна «Найти цену» (по прайсу); раскрытия «Источники» с сайтами нет. Под ценой — «из прайса: …» или «… — уточнить у менеджера»; у старой веб-цены — «цена из интернета — в КП не идёт» |
| Виджет 1.2.7: настройки и база | `KpSettings.tsx`, `KbPrices.tsx` | убраны настройки веб-поиска: коэффициенты к рынку, срок кэша, вызовов на позицию, дневной лимит, «Не брать цены из базы знаний». Убрана ручная «Добавить цену» в разделе «Цены»: такие строки в КП больше не идут. Вкладки «Веб» и «Правки» остаются — посмотреть и удалить; в сводке «(в КП не используются)» |

32 строки базы не из прайсов (31 из интернета 16–19.10, 1 правка менеджера) не удалены: в КП они больше не попадают.
Удалить их можно в виджете (раздел «Цены», вкладки «Веб» / «Правки», ×) — после выгрузки базы («Выгрузить в xlsx») и решения заказчика.
Посмотреть их:

```sql
SELECT id, origin, model, base_size, price, valid_at::date FROM kb_prices
WHERE account_id = 28528549 AND origin <> 'price_list' ORDER BY origin, id;
```

Что осталось в коде без вызова из КП: модуль рыночного поиска (`market-research.ts`, `offer-price.ts`) и консольная утилита
`apps/opt-worker/src/research-one.ts` для разовой ручной проверки. Из виджета и из «Найти цены» они не вызываются. Если нужно —
удалю отдельной задачей. Маршрут `POST /widget/v1/kb/prices` (ручная строка базы) остался без кнопки; такие строки в подбор не идут.
