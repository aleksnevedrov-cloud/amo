# RFD-AI-AGENT-OPT-KB-PRICES-UI: раздел «Цены» без портянки

Дата: 16.10.2026. Ветка `claude/opt-kb`, отдельный коммит после e02b260 (KB-PRICELIST). Только виджет (`apps/opt-widget`),
версия 1.1.5; сервер, пакеты опта, розница и ядро не менялись.

## Что сделано

| Пункт | Где | Содержание |
| --- | --- | --- |
| 1. Свёрнуто по умолчанию | `apps/opt-widget/src/components/KbPrices.tsx` (`PricesSection`, `pricesSummary`, `summaryText`) | одна строка-сводка: «Прайс: 28 цен · актуален на 16.10.2026 · файл «475-2016 CPL.xlsx»  \|  веб-цены: 16  \|  правки менеджера: 1»; без прайса — «Прайс не загружен». Число цен — со склонением (1 цена, 2 цены, 28 цен); дата — самая поздняя `validAt` среди строк прайса; файл — источник прайсовых строк (после замены прайса он один). В сводку «правки менеджера» входят записи `manager` и `purchase` |
| 2. «Показать» | там же | кнопка «Показать» / «Скрыть» рядом с «Выгрузить в xlsx». В раскрытом виде: вкладки «Прайс (28) / Веб (16) / Правки (1)», поле «поиск по модели» — фильтр по вводу (модель или фабрика, без регистра, страница сбрасывается), страницы по 20 строк с переходами «← 1–20 из 28 →»; колонки: модель (с фабрикой), размер, цена, НДС, дата, источник (файл прайса, сайт веб-цены или примечание правки) |
| 3. Только чтение у прайса | там же | у строк прайса кнопки удаления нет; у веб-цен и правок — «×» с подтверждением, как раньше. Ручная запись («Модель», «800×2000», «цена, ₽», «Добавить цену») осталась внутри раскрытого раздела, после записи открывается вкладка «Правки» |
| 4. Обновление без перезагрузки | `KnowledgeBase.tsx` | раздел получает счётчик `version`, который растёт после любого действия с источниками (загрузка файла, удаление, переиндексация) и после импорта из панели «Цены из прайса»; список перечитывается, раскрытие и выбранная вкладка не сбрасываются. Раньше раздел пересоздавался по `key` только после импорта из панели |
| 5. Плитка позиции | — | «найдено по прайсу: … (строка N)» не трогалось |

Список берётся одним запросом `GET /kb/prices?limit=1000`, вкладки, поиск и страницы считаются в виджете; при базе больше 1000 строк показываются первые 1000 (сервер отдаёт по ключу модели).

```bash
cd /opt/agent-opt/src && git fetch origin claude/opt-kb && git checkout <коммит>
WIDGET_API_URL=https://opt.rf-dveri.ru pnpm opt-widget:build && cp apps/opt-widget/dist/widget.zip /opt/agent-opt/dl/widget-opt-7c1e.zip && md5sum /opt/agent-opt/dl/widget-opt-7c1e.zip
```

Контейнеры пересобирать не нужно. В amo — виджет 1.1.5 (`?v=115`).

## Приёмка

1. Вкладка «База знаний» → раздел «Цены»: одна строка сводки с числом цен прайса, датой и именем файла, числом веб-цен и правок.
2. «Показать» → вкладки «Прайс / Веб / Правки» с числами, поиск по модели по мере ввода, страницы по 20; у строк прайса нет «×», у веб-цен и правок есть.
3. Загрузить новый прайс или удалить файл — сводка и вкладки меняются сразу, без обновления страницы.
