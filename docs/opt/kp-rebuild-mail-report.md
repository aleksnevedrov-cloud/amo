## Приёмка (сделка 89933, #30017381)

1. Черновик 51 (пустой) можно оставить: «Собрать заново» → если письмо найдено — новый черновик с 4 позициями; черновик 27 с документом остаётся в истории (новый черновик всегда последний).
   Примечание: у пустого черновика 51 папки и UID письма нет, поэтому первая пересборка идёт обычным поиском (150 с, с повтором порций); начиная со следующей — по сохранённому UID за секунды.
2. Проверка защиты: в сделке с рабочим черновиком временно отключить ящик (неверный пароль во вкладке «Письмо» или пустая карточка) → «Собрать заново» → тот же черновик с пометкой «пересборка … без позиций … — черновик сохранён», в журнале `kp_error` «Черновик N сохранён».
3. Спецификация с «2100 (h) × 900» → в плитке и КП название без «(h)».
