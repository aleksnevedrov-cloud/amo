## Прокси и `NO_PROXY`

ТЗ просит качать записи без `HTTPS_PROXY` и добавить `megapbx.ru`, `onpbx.ru` в `NO_PROXY`. Делать это не нужно: образ опта — `node:22-alpine`, а глобальный `fetch` в Node 22 переменные `HTTPS_PROXY` / `NO_PROXY` не читает вовсе (поддержка через `NODE_USE_ENV_PROXY` появилась только в Node 24). В коде опта `ProxyAgent` / `setGlobalDispatcher` нигде нет — все исходящие запросы из opt-api и opt-worker идут напрямую с IP сервера. Скачивание записей — тоже, что и подтвердил ваш замер 22.10 (`200 audio/mpeg`).

Из этого же следует, что вызовы OpenAI из Node сейчас через `HTTPS_PROXY` из `.env` не ходят. Если прокси для OpenAI на самом деле нужен, это отдельный вопрос вне этого ТЗ — скажите, посмотрю.

Асинхронное распознавание Яндекс SpeechKit (длинные записи, разделение каналов) принимает аудио только по ссылке из Yandex Object Storage, а не файлом.
