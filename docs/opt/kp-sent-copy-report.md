# KP-SENT-COPY — копия отправленного КП в «Отправленные» и просмотр письма

Ветка `claude/opt-kb`. Коммиты кода — `26a839f` и `68b2ce7` (поле «Папка отправленных» без значения по умолчанию), вместе +1042 / −26 строк, 19 файлов. Виджет «Агент опт» **2.0.6**. Миграций нет. Розница не тронута (`git diff 06d538d -- packages/retail apps/api apps/worker apps/widget packages/core` — пусто; новый вид записи журнала `kp_sent_copy_failed` объявлен в опте, общий `JournalKind` не менялся).

## Почему письма не было в «Отправленных»

SMTP Яндекса (smtp.yandex.ru:465) сам письмо в «Отправленные» не кладёт — это делает почтовый клиент. nodemailer только отправлял письмо, копию никто не сохранял. Поэтому КП-2026-16 (черновик 80, сделка 90025) в ящике rf-dveri@yandex.ru не видно. В журнале `kp_sent` (id 1462) были только адрес, копия, номер и имя вложения — messageId не записывался.

## Настройки ящика Яндекса

Для копии в «Отправленные» нужен вход по IMAP с тем же логином и паролем, что и для SMTP. Чтение письма заявки (кнопка «Собрать КП») уже ходит по IMAP в этот ящик. Если оно работает, отдельных действий скорее всего не нужно — проверит «Проверить IMAP».

Если «Проверить IMAP» показывает «вход … не удался»:
1. Яндекс Почта → «Все настройки» → «Почтовые программы»: включить «С сервера imap.yandex.ru по протоколу IMAP» и способ авторизации «Пароли приложений и OAuth-токены».
2. Пароль во вкладке «Письмо» должен быть паролем приложения (Яндекс ID → «Безопасность» → «Пароли приложений», тип «Почта»), а не основным паролем аккаунта. Тот же пароль работает и для SMTP.

Если папка не нашлась — вписать её имя в «Папка отправленных». У Яндекса папка «Отправленные» обычно отдаётся с признаком `\Sent` и находится сама.
