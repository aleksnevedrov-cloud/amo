## Правило подбора аналога (`packages/opt/kp/src/analog.ts`)

Решения заказчика 12.10.2026 (после коммита 2f5083d).

| Правило | Решение |
| --- | --- |
| Источник кандидатов | интернет, сайты производителей — в приоритете; маркетплейсы и агрегаторы — только дополнительные источники цены. Каталог розницы не используется. |
| Как подключается | кандидатов находит поиск рыночных цен этапа 9 (web_search, `docs/tz-kp-market-pricing.md`, раздел 6.4); `rankAnalogs` / `suggestAnalog` — фильтр и ранжирование найденного. Само подключение web_search — на этапе 9. |
| Критерии, по порядку | ГОСТ/техтребования из заявки → дизайн → цена; порядок заказчику не принципиален, оставлен как есть. Веса 100 / 10 / 1: источник (сайт производителя +0,3) решает только при равных критериях. |
| Опорная цена для критерия «цена» | по порядку (`referencePrice`): медиана по точной модели, если она найдена → цена, которую менеджер проставил в строке черновика → нет ни того, ни другого: критерий пропускается, подбор только по ГОСТ/техтребованиям и дизайну, в пометке «цена не сравнивалась». В деталях совпадения по цене пишется, какая опорная цена взята. |
| Допуск цены | не более ±10 % (было 15 %). Настройка КП «Допуск цены аналога, %» (`constants.analogPriceTolerancePct`, по умолчанию 10, схема API не принимает больше 10; `priceToleranceOf` режет и в коде). |
| Вид источника | определяет модель по домену и странице. Настройка КП «Домены производителей» (`constants.manufacturerDomains`, по одному в строке, пусто по умолчанию): источник с таким доменом или его поддоменом всегда считается сайтом производителя (`sourceKindOf`, `isManufacturerDomain`). |
| Статусы и пометки расчёта | `research-notes.ts`: порога «мало источников — цену не ставить» нет. Один-два источника — цена ставится с пометкой «ограничение расчёта: N источник(ов)»; только по аналогу — «предварительно, по аналогу»; 3–5 источников — цель, не блокировка. Цена не ставится только при нуле источников (`none`) или ошибке поиска (`failed`). |
| Цена строки КП | аналог идёт в цену строки как предварительный — через правило цены этапа 9 (медиана × коэффициент), не напрямую. Пометка «предварительно, по аналогу: <фабрика, модель, источник>» в материалах расчёта и в `needs_manager`. Если цена позиции посчитана только по аналогам или по одному источнику — ещё «ограничение расчёта». |
| Доставка и монтаж | в КП не считаются и не ставятся. Цена источника с включённой доставкой/монтажом без указанной суммы в сравнение не берётся (`comparablePrice` = null); сумма указана явно — вычитается. |
| Материалы расчёта по каждому аналогу | ссылка и дата (`source.url`, `source.foundAt`), цена для сравнения, налоговый статус источника (`source.vatStated`), совпавшие критерии (`matched`) и чем именно (`detail`). |

Критерии и откуда данные:

| Критерий | Заявка | Кандидат (из веб-поиска) |
| --- | --- | --- |
| ГОСТ / техтребования | `extractRequirements`: ГОСТ, ТУ, СТО, СНиП, СП из письма и позиций; плюс `requirements` разобранных спецификаций (@core/docs) | `standards` и название предложения |
| Дизайн | слова от 4 букв из позиции (покрытие, цвет, коллекция, остекление); общие слова «дверь», «полотно» не считаются | `design` + название предложения |
| Цена | опорная цена (`referencePrice`): медиана по точной модели (этап 9) или цена менеджера в строке; у свежего черновика нет ни той, ни другой — критерий пропускается | `price` минус явно указанная доставка (`comparablePrice`) |

Сейчас в `job.ts` зависимость `analogs` не подключена: до этапа 9 черновик собирается без предложений
аналогов, а правило, настройки (допуск, домены производителей) и пометки статусов готовы и покрыты
тестами (`test/analog.test.ts`, `test/research-notes.test.ts`).

## Фраза о ценах (`price_note`)

Текст по умолчанию: «Цены носят ориентировочный характер и могут быть скорректированы после уточнения
всех деталей заказа.» Редактируется в настройках КП → константы → «Фраза о ценах» (`constants.priceNote`);
пустое поле — без фразы.

Место в шаблоне `kp.docx`: плейсхолдер `{{price_note}}` отдельным абзацем сразу под итогом —
после `{{grand_total}}` / `{{total_in_words}}` / `{{vat_phrase}}`, перед условиями оплаты и подписью.
Если в шаблоне тега нет, фраза всё равно попадает в каждое КП: добавляется строкой после `{{vat_phrase}}`,
а в журнале сборки пишется «в шаблоне нет {{price_note}} — фраза о ценах добавлена под строку НДС».
