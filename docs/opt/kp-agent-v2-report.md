## Вкладка в карточке сделки (п. 6а) — что выяснено

Ширину правой колонки CSS-ом не меняли. Своя вкладка карточки в amoCRM возможна через Card SDK, но включить её из кода виджета нельзя:
- в `manifest.json` нужна область `card_sdk` и место `lcard-0`;
- в `script.js` — колбэки `loadPreloadedData`, `loadElements`, `linkCard`, `searchDataInCard`;
- вкладку к карточке подключает администратор аккаунта в настройках виджета, после переустановки.

Поэтому работа с КП — в окне на 88 % экрана из узкой колонки. Его можно позже перенести во вкладку без переделки сервера. Источники (сайты документации amo из сессии недоступны, сведения — по поиску):
- kommo.com/developers/content/web-sdk/sdk_card;
- www.kommo.com/developers/content/integrations/sdk_card/;

## Отличия от задания и открытые вопросы

1. **Нет настоящих файлов 8 сделок.** Набор их пропускает с пометкой, пока не выгружены `flow-export`.
2. **Разбор письма моделью в наборе не повторяется.** Для заявок «только письмо» позиции берутся из ответа модели, сохранённого в `letterItems`.
3. **«Неполная позиция» не блокирует, если цена уже подтверждена** (прайсом, менеджером или выбором из интернета) и не пусты количество и размер. В КП тогда нет обозначения по ГОСТ — менеджер видит вопрос жёлтым.
4. **Повторный поиск в интернете — по сроку кэша поиска** (`researchCacheDays`). Флаг `force` из старых виджетов, как и в KB-WEB-ROWS, поиск не повторяет.
5. **Ставка НДС.** Если в настройках «Ставка НДС» пуста, в КП теперь «в т.ч. НДС 22 %», а раньше было «НДС не облагается». 0 в настройке — «НДС не облагается».
