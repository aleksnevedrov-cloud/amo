## Автосохранение правок таблицы (п. 3а ТЗ)

| № | Как сделано |
|---|---|
| 1 | `edit()` (цена, количество, скидка) и выбор двери у комплектующего (через `act`) → таймер 1,5 с → `save()` → `PUT /kp/draft/:id` с текущими строками; новый ввод перезапускает таймер |
| 2 | `save()` держит `inFlight`: пока идёт запрос — ждёт; правка во время запроса (`editSeq` вырос) — ответ обновляет только черновик, строки остаются локальные, следующее сохранение сразу после текущего с последними строками |
| 3 | Индикатор над таблицей (`.opt-kp-save`): «Сохраняю…», «Сохранено», «Не сохранено: <причина> — повторю через 5 с» + «Повторить»; автоповтор через 5 с, не больше 3 раз |
| 4 | `act()` и `findPrices()` сначала `ready()`: несохранённая правка — сохранение сразу, потом действие; ошибка — «Правки не сохранены: …», действие не выполняется. Подсказки «Сначала сохраните правки» нет; сборка блокируется только полями с неверным значением |
| 5 | ✕, Esc, клик мимо окна → `ready()` → сохранить сразу → закрыть; при ошибке окно остаётся, причина в индикаторе и в строке ошибки |
| 6 | `beforeunload` → `fetch(saveLink, { method: 'POST', keepalive: true, headers: { 'content-type': 'text/plain' }, body })`. Заголовок X-Auth-Token amo из iframe при выгрузке не подставить, поэтому при первой правке виджет берёт подписанную ссылку `GET /kp/draft/:id/save-link` (HMAC, 10 минут, привязана к аккаунту и черновику — как ссылка на файл КП); `POST /kp/draft/save` принимает text/plain (простой запрос без preflight) и сохраняет через ту же `saveDraftLines` |
| 7 | Цена ≥ 0 или пусто, количество ≥ 0,5, скидка 0–100; неверное значение остаётся в поле красным (`.opt-kp-input-invalid`), не сохраняется, таймер снимается; сборка — «Исправьте поля, выделенные красным» |
| 8 | Ручная цена — как раньше: `priceSource: manager`, «изменено менеджером», подпись «фабрика · наценка · цена» пропадает |
| 9 | `built` / `sent`: поля таблицы `disabled`, `edit()` и автосохранение не срабатывают |

```bash

```

Виджет 2.0.9, архив `widget-opt-2009.zip` (location уже в `scripts/opt/nginx-opt.conf` — скопировать конфиг на место и перечитать nginx):
```bash
cd /opt/agent-opt/src
docker run --rm -v "$PWD":/app -w /app -e WIDGET_API_URL=https://opt.rf-dveri.ru ai-door-build sh -c 'pnpm install --frozen-lockfile && pnpm opt-widget:build'
mkdir -p /opt/agent-opt/dl && cp apps/opt-widget/dist/widget.zip /opt/agent-opt/dl/widget-opt-2009.zip

cd /opt/agent-opt && docker compose exec nginx nginx -s reload
curl -sI https://opt.rf-dveri.ru/dl/widget-opt-2009.zip | head -1
```
