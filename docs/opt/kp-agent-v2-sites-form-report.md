## Что было

В 2.0.0 комментарий сайта задавался только через xlsx. В карточке ссылки было поле без подписи — только с подсказкой внутри. После загрузки xlsx оно не обновлялось, поэтому сохранённый комментарий в нём не показывался.

## Как теперь

| Пункт | Где | Содержание |
| --- | --- | --- |
| 1. Форма «Добавить ссылку» | `KnowledgeBase.tsx` (`AddUrl`) | под полем «Ссылка»: многострочное «Комментарий» (до 2000 знаков, счётчик) и чекбокс «Фабрика». Уходят вместе со ссылкой; после добавления форма очищается |
| 1. Сервер | `routes/kb.ts`, `POST /kb/sources/url` | поля `comment` (до 2000, иначе 400 «комментарий — не длиннее 2000 знаков») и `isFactory`. Повторная та же ссылка их обновляет; без полей прежние значения не трогаются. В журнале — «…, фабрика, комментарий: «…»» |
| 2. Карточка ссылки | `KbSites.tsx` (`SiteMeta`) | у сайта (не у страницы раздела) — подписанные поля «Комментарий» и «Фабрика» с сохранённым значением; кнопка «Сохранить» активна, когда есть изменения. После сохранения и после загрузки xlsx поля показывают значение из базы |
| 3. Выгрузка / загрузка xlsx | — | без изменений |
