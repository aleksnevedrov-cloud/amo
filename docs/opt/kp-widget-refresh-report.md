# RFD-AI-AGENT-OPT-KP-WIDGET-REFRESH: виджет не обновлял позиции после «Найти цены»

Дата: 17.10.2026. Ветка `claude/opt-kb`, коммит b65c77b (после e48e26e, KP-LAYOUT). Только виджет (`apps/opt-widget`),
версия 1.1.9; сервер не менялся. Розница и ядро не менялись.

## Причина (сделка 90025, черновик 54, лог 17.10 06:22:00; то же 16.10 на черновике 50)

| В логе | Причина в коде |
| --- | --- |
| `POST /kp/research` → 202, один `GET /kp/research?draftId=54`, дальше ни одного запроса; `GET /kp/draft` не вызывался | `KpBlock.tsx`, `loadResearch`: черновик перечитывался только при переходе «был в работе → завершился» (`!r.pending && wasPending.current`). Флаг «был в работе» ставился лишь по ответу опроса с queued/running. Цены из базы знаний ложатся за доли секунды — к первому опросу после POST заданий уже нет, `pending: false`, флаг не стоял, перечитывание не запускалось, опрос по таймеру не включался (он идёт только пока `pending`). Виджет оставался со старым черновиком: «Нет цены», «Итого 0 ₽», серая «Собрать документ». После F5 черновик читался заново — цены появлялись |

Дополнительно: перечитывание блокировалось флагом `dirty` (несохранённые правки) — тогда цены тоже не показывались до F5.
