## Новые переменные `.env`

Нет. Переменные скрипта бэкапа (необязательные, для cron): `OPT_DIR` (по умолчанию `/opt/agent-opt`), `KB_BACKUP_DIR` (`$OPT_DIR/backups/kb`), `KB_BACKUP_KEEP` (7).

## Развёртывание

```bash
cd /opt/agent-opt/src && git pull
cd /opt/agent-opt
docker compose build opt-api opt-worker
docker compose up -d opt-api opt-worker                 # новых миграций нет
bash src/scripts/opt/kb-backup.sh --dry-run             # посмотреть команды
bash src/scripts/opt/kb-backup.sh                       # первая копия: /opt/agent-opt/backups/kb/kb-<дата>.sql.gz
bash src/scripts/opt/kb-backup.sh --install-cron        # crontab root: 40 3 * * * … (ежедневно 03:40, 7 копий)
crontab -l | grep kb-backup
```

Виджет: пересобрать архив (`pnpm opt-widget:build`, версия 1.1.0) и обновить в amoМаркете — в карточке сделки новая карточка «Ответ из базы знаний».
