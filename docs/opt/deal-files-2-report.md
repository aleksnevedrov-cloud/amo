## к1 — дубли файлов и наш документ (`3465cee`)

| № | Как сделано |
|---|---|
| 2.1.1 | `fileKey`: имя без расширения, нижний регистр, ё → е, пробелы и «_» схлопнуты, плюс размер в байтах. Вложение письма с тем же ключом, что файл сделки, — тот же файл (его и загрузили в сделку): берётся из памяти письма, считается файлом сделки |
| 2.1.2 | `parseFiles`: после скачивания, до разбора — SHA-256 содержимого; одинаковые байты под любыми именами — один файл (`Map<sha, файл>` на время задания) |
| 2.1.3 | Порядок источников: «Файлы» сделки → вложения письма → Яндекс Диск; повтор — в «пропущено» и в файлах окна КП: «повтор файла «Двери внутренние Данилково (4)» из «Файлов» сделки» (из вложений письма / с Яндекс Диска). Файл с теми же именем и размером, но другими байтами, разбирается (поэтому по ключу перед скачиванием не отсеиваем) |
| 2.1.4 | Повторный разбор того же содержимого в рамках одной сборки невозможен: хэш проверяется до вызова разбора; повторы не занимают лимит 10 файлов |
| 2.2.1 | `isOurDocument`: вид документа — `kind = estimate` или название / имя файла (счёт, коммерческое предложение, КП, договор, УПД, накладная) **и** в тексте — ИНН / КПП из `sellerRequisites` (9 / 10 / 12 цифр) или название из `sellerName` и варианты «РУС-ДВЕРИ», «РУС ДВЕРИ», «РУСДВЕРИ» (нормализация без кавычек, ООО, дефисов и пробелов). Текст — сырой, из файла до чистки персональных данных (`rawText`): чистка убирает строки с ИНН и «счёт» |
| 2.2.2 | Позиции нашего документа в черновик не берутся; в «Письме и файлах» — «наш документ (продавец ООО «РУС-ДВЕРИ»), позиции не берутся» (status skipped); позиции сохраняются в `payload.ownDocs` |
| 2.2.3 | `kind = estimate` не наш — позиции берутся, у файла и в пометках менеджеру: «из сметы другого поставщика: <название> — позиции взяты из неё, проверьте» |
| 2.2.4 | Нет ни одной позиции от других файлов и есть `ownDocs` — вопрос опросника `own_document` (блокирующий): «В сделке только наш счёт «…» — взять его позиции?», «Да, взять позиции» / «Нет, оставить черновик без позиций»; «Да» — `request_items` / `items` из позиций документа, пометка «позиции взяты из нашего документа по решению менеджера» |
