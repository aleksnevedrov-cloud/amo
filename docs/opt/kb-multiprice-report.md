## Приёмка

1. Загрузить оба файла → сводка «Прайсы: Межкомнатные — 54 цены (16.10) · Металлические — 21 цена (16.10)», в карточках файлов «прайс «Межкомнатные»: цен 54» и «прайс «Металлические»: цен 21».
2. #30022107 «Собрать заново» → «Найти цены» → три позиции по 23 900 «по прайсу: ДВ CPL (строка N)», веб-вызовов 0.
3. Перезалить металлические (любое имя с тем же началом: «… — обновил 16102026.xlsx») → сообщение «прайс «Металлические» обновлён: было 21, стало N; удалено M, добавлено K», межкомнатные 54 не тронуты; у прежнего файла металлических «цен 0» — его можно удалить.
4. Удалить металлические → межкомнатные на месте, сводка «Прайс: Межкомнатные — 54 цены (16.10)».
