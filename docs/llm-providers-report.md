## Отклонения и решения

- **Единственная правка существующего теста** — `apps/widget/test/build.test.ts`: ожидаемая версия архива `1.0.1` → `1.1.0`,
  как требует ТЗ. Остальные 366 тестов проходят без изменений (п. 0.4).
- **Повторы при `rate_limit`/`overloaded`/`timeout`** делают SDK обоих провайдеров (2 повтора с экспоненциальной паузой,
  `maxRetries: 2`), после чего шлюз переключает модель; отдельного третьего слоя повторов нет — иначе на сбой уходило бы до 9 попыток.
- **Кнопка проверки ключа** называется «Проверить» (в поле «Ключ Anthropic Claude»), а не «Проверить ключ» — так на неё
  ссылаются существующие тесты и инструкция; рядом зелёная/красная метка «ключ действует» / «ключ не принят».
- **Резервная модель по умолчанию** — того же провайдера (`claude-sonnet-5`), как в 1.0.1: не требует второго ключа
  (вопрос 3 раздела 10). Резерв другого провайдера выбирается в списке, когда сохранён его ключ.
- **Валюта учёта** — ₽ по курсу (как было); переключатель «$» в «Лимитах» меняет только отображение (вопрос 2 раздела 10).
- **Прогон eval из виджета** идёт на тестовом каталоге (как и CLI): ожидания диалогов привязаны к нему; на живом каталоге
  показатель «выдуманные данные» смотрится через «Сравнить» в песочнице.
- **Модель «AI готовит ответ» (синий индикатор)** включается, пока есть необработанное вложение; отдельного события
  «модель думает» от бэкенда нет.
- **«Отправить клиенту»** у товара и расчёта вставляет текст в поле чата (или копирует в буфер), отправляет менеджер —
  панель не пишет в чат от имени AI без подтверждения.

## Что сверить по документации (п. 0.2) — при получении ключей

1. **Тарифы OpenAI** в `packages/llm/src/pricing.ts` (`DEFAULT_PRICING.openai`) заполнены по прайс-листу на момент
   реализации без доступа к сайту OpenAI из среды сборки — сверить с platform.openai.com/pricing и поправить в коде или
   в «Лимитах» → «Тарифы моделей». Тарифы Anthropic перенесены из 1.0.1 без изменений.
2. Названия актуальных моделей OpenAI подтягиваются из `GET /v1/models`; фильтр чат-моделей — по семействам
   (`gpt-5*`, `gpt-4.1*`, `gpt-4o*`, `o3*`, `o4*`, `gpt-6*`; исключены аудио, эмбеддинги, картинки, `*-chat-latest`, `*-pro`).
   Если у заказчика появится модель вне этих семейств — добавить в `modelTraits`.
3. Responses API: `store: false` + `include: ['reasoning.encrypted_content']` и повтор items ответа как есть —
   по документации OpenAI для многошаговых вызовов инструментов без хранения на стороне OpenAI; проверить на живом ключе.
4. `temperature` у Claude: по описанию SDK не поддерживается моделями после Opus 4.6 — адаптер не передаёт её таким моделям.

## Открытые вопросы к заказчику (раздел 10)

1. Ключ OpenAI — вводится заказчиком в «Модель» после выпуска 1.1.0; для критерия 4 нужен ключ на прогон (≈ $3–8).
2. Валюта учёта — оставлено ₽ по курсу, переключатель на $ есть.
3. Резервная модель по умолчанию — того же провайдера; менять не нужно, если заказчик не решит иначе.
