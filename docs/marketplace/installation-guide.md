# AI-продавец дверей — установка и настройка за 30 минут

> Инструкция для карточки виджета в amoМаркете. Пометки `[скриншот N]` — места, где при подаче вставляются
> снимки экрана с живого аккаунта (список в конце).

## Что понадобится
- Права администратора в amoCRM.
- Ключ Anthropic: https://console.anthropic.com → API Keys → Create Key. Оплата — по тарифам Anthropic.
- Фид каталога в формате YML (Яндекс.Маркет) — ссылка с вашего сайта.
- По желанию: ключ Yandex Cloud для голосовых и распознавания фото (иначе фото распознаются встроенным Tesseract).

## Шаг 1. Установите виджет
amoМаркет → «AI-продавец дверей» → «Установить» → разрешите доступ к данным аккаунта. `[скриншот 1]`
После установки откройте виджет → «Настройки» (шестерёнка) → «Расширенные настройки».

## Шаг 2. Подключите модель
Вкладка «Модель» → вставьте ключ Anthropic → «Проверить» → «Сохранить ключ». Ключ хранится зашифрованным и больше
не показывается. `[скриншот 2]`

## Шаг 3. Загрузите каталог
Вкладка «Каталог» → адрес фида YML → «Сохранить» → «Обновить сейчас». Через минуту появится число товаров. `[скриншот 3]`

## Шаг 4. Расскажите агенту о магазине
- «Поведение»: характер общения, правила магазина, запрещённые темы, приветствие, фраза передачи менеджеру.
- «База знаний»: FAQ (доставка, оплата, гарантия, сроки), тексты о покрытиях, статьи по ссылкам.
- «Правила цен»: состав комплекта, цены комплектующих по сериям, наценка за нестандарт, услуги. Можно загрузить XLSX.
  Пока правил нет, агент не называет итог, а ставит менеджеру задачу на расчёт. `[скриншот 4]`

## Шаг 5. Проверьте в песочнице
Вкладка «Песочница»: напишите как клиент («Нужна белая дверь в спальню, проём 80 на 200»). Вы увидите ответ,
вызванные инструменты и источники. Клиенту ничего не уходит. `[скриншот 5]`

## Шаг 6. Подключите чаты
1. Salesbot → создать бота → шаг «Виджеты» → «AI-продавец: ответить клиенту». `[скриншот 6]`
2. Digital Pipeline → на этапах, где работает агент, триггер «Входящее сообщение» → запуск этого бота.
3. Для режима «Полуавто» создайте второго бота с шагом «AI-продавец: отправить одобренный черновик» и укажите
   его номер в «Где работает» → «Бот-отправщик».
Подробно и с оговорками про версии amo — docs/install.md, раздел 7.

## Шаг 7. Включите агента
Вкладка «Статус»: «Включён», режим. Рекомендуем начать с «Полуавтоматический»: агент готовит черновики, вы одобряете
одной кнопкой в карточке сделки. Когда ответы устраивают — «Автоматический». `[скриншот 7]`

## Что дальше
- «Где работает»: воронки и этапы, этапы «без AI», склейка сообщений, голосовые, файлы и фото.
- «Передача менеджеру»: тип задачи, срок, ответственный, этап при передаче.
- «Лимиты»: дневной лимит в рублях и лимит ответов на сделку.
- «Почта»: ответы на письма клиентов с вашего ящика (docs/email-yandex.md).
- «Аналитика», «Журнал», «Версии» — контроль и откат.

## Если что-то не так
- «Нет ключа Anthropic» в статусе — шаг 2.
- Агент молчит — проверьте, что сделка в разрешённой воронке и не на этапе «без AI», а менеджер не писал клиенту
  последним (тогда агент на паузе — кнопка «Вернуть AI» в карточке).
- Все действия и ошибки — во вкладке «Журнал».
- Поддержка: rf-dveri@yandex.ru.

## Список скриншотов для подачи
1. Карточка виджета в amoМаркете с кнопкой «Установить».
2. Вкладка «Модель» с сохранённым ключом («Используется ключ вашего аккаунта»).
3. Вкладка «Каталог» после импорта.
4. Вкладка «Правила цен».
5. Песочница с ответом и инструментами.
6. Конструктор Salesbot с шагом виджета.
7. Вкладка «Статус» с включённым агентом.
8. Панель в карточке сделки: черновик ответа с кнопками «Отправить»/«Отклонить».
