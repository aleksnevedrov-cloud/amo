# Карточка виджета для amoМаркета

Издатель: ООО «РУС-ДВЕРИ» (РФ-Двери), ИНН 9706000520, https://rf-dveri.ru · Поддержка: rf-dveri@yandex.ru · Бесплатно (ключ Anthropic — свой).

## Название
AI-продавец дверей

## Короткое описание (до 100 символов)
AI-агент отвечает клиентам в чатах amoCRM как продавец дверей: подбор, расчёт, файлы, передача менеджеру.

## Полное описание

AI-агент ведёт переписку с клиентом от имени вашего магазина дверей прямо в amoCRM — в WhatsApp, Telegram, Max,
Авито и чате сайта через Salesbot, а также по электронной почте.

**Что умеет**
- Подбирает двери из вашего каталога (фид YML) и объясняет разницу покрытий по вашей базе знаний.
- Считает стоимость комплекта по вашим правилам: полотно, коробка, наличники, доборы, доставка, монтаж. Расчёт —
  черновик детализации в примечании сделки.
- Разбирает файлы клиента: фото замерного листа, PDF, Excel, Word, чертежи DWG — размеры проёмов, позиции
  спецификаций, комплект по замеру. Голосовые сообщения расшифровывает.
- Ставит задачи менеджеру (перезвонить, отправить КП, проверить наличие, замер) и передаёт диалог человеку, когда
  клиент просит, жалуется, спрашивает скидку, покупает на юрлицо или оптом.
- Помнит клиента: размеры, бюджет, предпочтения, понравившиеся модели — при следующем обращении не спрашивает заново.

**Без выдуманных цен.** Каждый ответ проверяется автоматически: цена, наличие или срок, которых нет в каталоге и
базе знаний, не уйдут клиенту. Если данных нет — агент уточняет или зовёт менеджера.

**Три режима.** Автоматический — агент пишет сам. Полуавтоматический — агент готовит черновик, менеджер одобряет
одной кнопкой. Подсказки — агент подсказывает менеджеру ответ в карточке сделки. Как только менеджер пишет клиенту
сам, агент замолкает.

**Под контролем.** Лимит расходов в день, лимит ответов на сделку, журнал каждого действия со стоимостью, аналитика
(диалоги, передачи, конверсия), история настроек с откатом, песочница для проверки перед запуском.

**Данные.** Сервер в России. Телефоны и e-mail клиентов не передаются провайдеру модели. Файлы не хранятся — только
результат разбора. Все данные аккаунта можно удалить одной кнопкой.

**Стоимость.** Виджет бесплатный. Вы подключаете свой ключ Anthropic и платите провайдеру напрямую; обычный диалог
стоит несколько рублей, расход виден в настройках.

## Скриншоты для карточки (сделать на живом аккаунте)
1. Панель в карточке сделки: статус AI, найденные товары, расчёт, файлы клиента.
2. Настройки → «Статус»: режимы, расход, здоровье интеграций.
3. Настройки → «Песочница»: диалог с показом инструментов и источников.
4. Настройки → «Правила цен»: таблица и тест расчёта.
5. Настройки → «Аналитика».
6. Salesbot: шаг «AI-продавец: ответить клиенту» в конструкторе.
