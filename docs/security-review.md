## Дополнительно проверено

- **SSRF.** Адреса фида, вложений amo и статей базы знаний проверяются `assertPublicUrl` (запрет приватных сетей,
  разрешение DNS перед запросом). Адреса OAuth и Salesbot — только домены amo.
- **Размеры входа.** Файлы до 20 МБ, base64 до 28 МБ, письма — 5 вложений, тексты документов режутся до 60/40 тыс.
  символов, сообщения в песочнице до 8 тыс.
- **Заголовки писем.** Наши письма помечены `X-AI-Door` и `Auto-Submitted`, автоответы и рассылки не обрабатываются,
  лимит ответов на адрес за сутки — защита от почтовых петель.
- **Зависимости.** Все в lock-файле, сборка приложений — ESM-бандл с явными внешними зависимостями.

## Сверить на боевом сервере

1. Формат подписи хука отключения виджета и `client_uuid` в токене виджета (п. 0.3).
2. TLS-терминация и заголовки прокси перед API (rate limit считает IP по `X-Forwarded-For` только за доверенным прокси).
3. Права сервисного аккаунта Yandex Cloud — только `ai.speechkit.stt` и `ai.vision.user`.
4. Ротация `TOKEN_ENCRYPTION_KEY` пока не автоматизирована: при смене ключа токены нужно перевыпустить (переустановка виджета).
